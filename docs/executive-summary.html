About the error “Predicted values must be in range [0, 1]”

That error fires when any cell (or the nodata sentinel, e.g. -3.4028234663852886e+38 from the feature stack) lies outside [0, 1]. This file contains no sentinel and no NaN anywhere: outside-footprint cells are literal 0.0 and nodata is unset, verified by re-opening the written bytes. If you ever regenerate a candidate, use the zeros policy (vendor/gems57/grid.write_submission(..., mode="zeros") / the fail-closed submission_writer) and re-validate the bytes you actually upload.
