Method — what we measure, what we do not claim

Every number is labeled HOLDOUT-DTI (evaluator version, N withheld, 95% CI) or ORGANIZER-CONFIRMED (copied from a submission-page receipt). A projection is never written as a score.

1. The metric and the decision rule that determines every dot

Official definition (problem page 967, verified 2026-10-21, two independent fetches agree; worked example TPw=3.00 FPw=1.89 FNw=2.00 → 0.6027, page rounds to 0.60, reproduced in tests/test_metric.py):

k(d) = max(1 − d/300m, 0),  R = 300m = 3 px at 100 m
TPw = Σ_g max_{x:d(x,g)≤R} p(x)·k(d(x,g))
FPw = Σ_{x:p(x)>0} p(x)·[1 − max_g k(d(x,g))]
FNw = Σ_g [1 − max_{x:d(x,g)≤R} p(x)·k(d(x,g))]
DTI = TPw / (TPw + 0.2·FPw + 0.8·FNw + ε)

Algebraic identity (proved in src/gems73/metric.py): with T=TPw, S=Σ p, M=Σ p·maxk, FNw=|G|−T exactly, so DTI = T/(0.2·(T+S−M)+0.8·|G|). Adding one unit of mass at weight k changes the denominator by 0.2, giving the credit bar: emit ⇔ k > 0.2·DTI. At group 0.2600 bar=0.0520; at leader 0.3262 bar=0.0652. GEMSDOE32 measured marginal credit 0.0548 — within 5% of the derived 0.0520 optimum.

3. The two-round objective

One file is scored twice: against the initial hidden set (Initial $50k) and against an expanded set that includes expert-verified new faults discovered from submissions (Final $250k). Writing objective as DTI1+ρ·DTI2, a dot with a plausible path to verification is worth emitting while E[k]+ρ·E[knovel] > 0.2·DTI — effective bar falls to 0.2·DTI/(1+ρ). Prize pools argue ρ>1; code default is conservative ρ=1. This is a strategy argument from published rules, not a measured effect.

5. This file's emission (Hydrothermal Permeability Corridor)

Layers [OFFICIAL band names from training_features.tif, read from reference solution notebook]: cond_surf, depth_to_base_surf, det_elev, det_elev_slope, dilatation, sis_rate, iso_grav_anom, rtp, tmi, rad_K/Th/TC (GeoDAWN), 1 m LiDAR ex_max/step_max/downface_max (3DEP links via competition CSV).

Physical signature (label-free — never reads labels.tif, no leakage): H(x) = D(x)^0.6 · A(x)^0.4 where D(x) = dilatational-jog proxy (fault-trace curvature × tip distance from mapped trace set, Coulomb-optimal 25° extensional jog) and A(x) = hydrothermal alteration-thermal proxy (radiometric K enrichment via Th/K shift + magnetic low halo + thermal inertia edge). Both components are robust-normalized (median/IQR, p99.5 clip) and the product peaks only where independent physics coincide — the definition of a geothermal-indicative fault.

Emission: Poisson-disk greedy max-cover at 2.8 px on the product surface, 37,654 dots, 0 within 2 px of synthetic catalogue by construction (real catalogue filtering uses existing_faults.tif when data/ is present). With data/, the same rule runs on the 19 official bands + pinned 3DEP/LiDAR/GeoDAWN layers (src/gems73/features.py); synthesis mode uses Walker Lane synthetic ridges with the same geometry and spacing.
