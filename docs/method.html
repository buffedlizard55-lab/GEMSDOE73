Stage 2 — 4-Quadrant LOQO 3-Expert Training with 3.0 km Boundary Buffer & Non-LiDAR Tail Alignment

For each quadrant q ∈ {NW, NE, SW, SE}, training samples are restricted to (quad != q) & (~boundary_buffer_3km), and out-of-fold predictions are calibrated across the 24.63% non-LiDAR gap via 2,001-quantile tail matching within each quadrant:

w_Q(x) = 0.42 - 0.22 * pi_pied(x)
w_P(x) = 0.24 + 0.10 * pi_pied(x)
w_S(x) = 0.34 + 0.12 * pi_pied(x)
S_M1(x) = [w_Q(x)*M_Q(x) + w_P(x)*M_P(x) + w_S(x)*M_S(x)] * G_shore_corrob(x)
S_M2(x) = clip(S_M1(x) * (1 + 0.26*T_tip + 0.22*W_wing + 0.26*R_relay + 0.20*S_H73_1_tail), 0, 1)

Stage 3 — Radius-Matched (d_min = 3.0 px) Lazy-Greedy 300 m Submodular DTI Allocation (M3)
